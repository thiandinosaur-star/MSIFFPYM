② 题目华语简单句子 + 答案提示方式

答题方式
题目 / Question
先看原 PDF 扫描，不改原题。
华语速译
只翻译题目要你做什么，不写一大段。
Answer / Theory 提示：答案保持考试用语；华语只补“为什么这样答 / 这个 theory 在讲什么”，避免把英文关键词翻坏。
State / Nyatakan写出 / 列出答案即可，通常不需要长解释。
Explain / Terangkan说明“为什么/怎样”，答案要有原因或机制。
Describe / Huraikan描述过程、变化或特征，按步骤/point 写。
Compare / Bandingkan同时写相同点或差异点；最好成对比较。
Calculate / Hitung先写公式 → 代入数值 → 单位。
Determine / Tentukan从资料/图表算出或判断最终结果。
Justify / Wajarkan给结论 + 支持结论的理由/证据。
Suggest / Cadangkan给合理方法，并尽量说明为何可行。
Relationship / Hubungan写清楚变量之间趋势：increases/decreases/direct/inverse。
Inference / Inferens根据观察结果推原因；实验题常用 depends on / because。
